
**MacをMatter対応のスマートホームデバイスに。**

クラウドやIFTTTを経由せず、Google HomeやApple Homeから直接、極めて低遅延でMacを操作できる常駐型アプリケーションです。

## 🚀 概要

Matter Mac Agentは、**Tauri**、**React**、**matter.js** で構築された軽量なメニューバー常駐アプリです。Mac上で仮想的なMatterブリッジとして機能します。

仮想のMatterスイッチに対して、macOSのシェルコマンド、AppleScript、または**macOS「ショートカット」アプリ**を自由に割り当てることができます。 「Hey Siri, 開発モードをオンにして」と言うだけで、ローカルネットワーク内で即座にIDEの起動、Dockerコンテナの立ち上げ、ウィンドウの配置などを一気に自動化できます。

## ✨ 主な機能

- **⚡️ 完全ローカル・超低遅延**: ご自宅のWi-Fi/IPv6ネットワーク上でMatterプロトコルを直接使用します。外部サーバーを経由しないため遅延がなく、API制限も一切ありません。

- **🛠 macOS「ショートカット」連携**: Mac標準の「ショートカット」アプリをネイティブにトリガー。ショートカットアプリで作れるものなら、何でもMatterから実行可能です。

- **🔒 セキュアな設計**: Tauriフレームワークを採用。ローカルサーバーのポート開放や外部APIへの依存はありません。安全なプロセス間通信(IPC)によりMacを保護します。

- **📦 かんたんセットアップ**: アプリ内に表示されるQRコードを、お使いのスマートホームアプリ（Google Home, Apple Home等）で読み取るだけでペアリング完了です。


## 💡 ユースケース

- 🧑‍💻 **開発モード**: 音声アシスタント経由でスイッチをONにすると、VS Codeが開き、Dockerが起動し、ブラウザで指定のGitHubリポジトリが開く。

- 🎬 **映画タイム**: 画面を暗くし、通知をミュート（おやすみモード）にして、Netflixを起動する。

- 🛑 **インスタント・スリープ**: 「Macを消して」で即座に画面をロックし、Macをスリープ状態にする。

- 🔄 **ブラウザリロード**: ローカルサーバーでの開発中、手元の物理スマートボタンを押して、アクティブなブラウザに `Cmd + R` （リロード）を送信する。


## 📥 インストール方法

_(注: インストール済みのバイナリは近日中に Releases ページで公開予定です)_

**一般ユーザー向け:**

1. Releasesページから最新の `.dmg` ファイルをダウンロードします。

2. アプリケーションを「アプリケーション」フォルダにドラッグ＆ドロップします。

3. アプリを起動し、求められた場合は「アクセシビリティ」や「オートメーション」のシステム権限を付与してください。


**開発者向け (ソースからのビルド):**

```bash
# リポジトリをクローン
git clone https://github.com/your-username/matter-mac-agent.git
cd matter-mac-agent

# 依存パッケージのインストール
pnpm install

# 開発モードで起動
pnpm tauri dev

# アプリケーションのビルド (.dmg の生成)
pnpm tauri build
```

## 🛠 使い方

1. **アプリの起動**: Matter Mac Agentを起動すると、メニューバーにアイコンが表示されます。

2. **ペアリング**: メニューバーからダッシュボードを開きます。表示されたMatter QRコードを、Google HomeまたはApple Homeアプリでスキャンします。

3. **アクションの割り当て**:

    - 画面上に10個の仮想スイッチ（エンドポイント）が表示されます。

    - スイッチの「編集」をクリックし、実行したいアクション（例: `StartDev` という名前のmacOSショートカット）を割り当てます。

4. **実行**: 音声アシスタントやスマートホームアプリからスイッチをON/OFFして、Macを操作しましょう！


## 🛡 セキュリティと権限について

Macのシステム操作を自動化するという性質上、本アプリはmacOSの**アクセシビリティ**および**オートメーション**権限を必要とします。

- 私たちは透明性を最重視しており、本プロジェクトは100%オープンソースとして公開しています。

- 本アプリが利用者の操作ログや個人情報を、ローカルネットワークの外部へ送信することは**一切ありません**。

- セキュリティ確保のため、シェルコマンドやAppleScriptの直接実行機能はデフォルトで無効化されています。これらを利用する場合は、設定から「開発者モード」を明示的に有効にする必要があります。
