## 1. Matter 通信仕様

### 1.1 ノード・エンドポイント構成

本アプリは Matter の **Bridge デバイスタイプ**として動作する。1つの Matter ノードを QRコード1枚でコミッショニングすることで、スマートホームアプリが配下の子デバイスを自動発見する。

エンドポイント構成（アプリバージョンをまたいで変更しない固定値）:

| Endpoint ID | デバイスタイプ | Device Type ID | 役割 |
|---|---|---|---|
| 0 | Root Node | 0x0016 | 管理用（Matter 必須・自動生成） |
| 1 | Aggregator | 0x000E | Bridge Device Type |
| 2 | Bridged Device + OnOff Plugin Unit | 0x010A | 仮想スイッチ 1 |
| 3 | Bridged Device + OnOff Plugin Unit | 0x010A | 仮想スイッチ 2 |
| 4 | Bridged Device + OnOff Plugin Unit | 0x010A | 仮想スイッチ 3 |
| 5 | Bridged Device + OnOff Plugin Unit | 0x010A | 仮想スイッチ 4 |
| 6 | Bridged Device + OnOff Plugin Unit | 0x010A | 仮想スイッチ 5 |
| 7 | Bridged Device + OnOff Plugin Unit | 0x010A | 仮想スイッチ 6 |
| 8 | Bridged Device + OnOff Plugin Unit | 0x010A | 仮想スイッチ 7 |
| 9 | Bridged Device + OnOff Plugin Unit | 0x010A | 仮想スイッチ 8 |
| 10 | Bridged Device + OnOff Plugin Unit | 0x010A | 仮想スイッチ 9 |
| 11 | Bridged Device + OnOff Plugin Unit | 0x010A | 仮想スイッチ 10 |

各 Endpoint 2〜11 は `Bridged Device Basic Information` クラスターを持ち、`nodeLabel` にユーザー定義名（デフォルト: 「仮想スイッチ N」）を設定する。

### 1.2 コミッショニング（ペアリング）フロー

```
① matter.js 起動
        ↓
② ペアリング情報を生成
   - QR コード文字列（MT: ペイロード形式）
   - Manual Pairing Code（11桁数字）
   - Discriminator（ハブが識別に使用）
   - Setup PIN（8桁）
        ↓
③ Sidecar → Rust: qr_code メッセージで送信
        ↓
④ Rust → React: Tauri IPC で転送
        ↓
⑤ React: QR コード画像と Manual Pairing Code を表示
        ↓
⑥ ユーザーがスマートホームアプリでスキャン
        ↓
⑦ Bridge ノード全体がコミッショニングされる
        ↓
⑧ スマートホームアプリが Endpoint 2〜11 を自動発見・登録
   → ユーザーのスマートホームに10個の独立スイッチが現れる
```

### 1.3 ON/OFF 状態同期

- スマートホームアプリ / 音声アシスタントから ON コマンドを受信 → matter.js の `onOff$Changed` イベント発火 → アクション実行
- アクション実行後、エンドポイントの OnOff 状態を最新値に保持する（スマートホームアプリでの状態確認に対応）
- OFF コマンドも同様

## 2. アクション仕様

### 2.1 アクション型定義

| `"type"` 値 | フィールド | 型 | 説明 | 権限 |
|---|---|---|---|---|
| `"shortcut"` | `name` | string | macOS ショートカット名 | 一般 |
| | `input` | string | `shortcuts run` の stdin 入力（空文字可） | |
| `"open"` | `target` | string | URL または `.app` パス | 一般 |
| `"shell"` | `command` | string | bash で実行するコマンド文字列 | **開発者モード限定** |
| `"applescript"` | `script` | string | `osascript -e` に渡すスクリプト | **開発者モード限定** |

### 2.2 バックエンド実行コマンド

| `"type"` | 実行コマンド |
|---|---|
| `"shortcut"` | `shortcuts run "{name}" <<< "{input}"` |
| `"open"` | `open "{target}"` |
| `"shell"` | `bash -c "{command}"` |
| `"applescript"` | `osascript -e '{script}'` |

### 2.3 アクション実行フロー

```
ハブから ON/OFF コマンド受信（matter.js の onOff$Changed イベント）
        ↓
Endpoint ID (2〜11) → スイッチ番号 (1〜10) に変換
  スイッチ番号 = Endpoint ID - 1
        ↓
config.json の endpoints[id=N].assigned_macro_id を参照
        ↓
config.json の macros から対象マクロを取得
  ON の場合: on_actions 配列
  OFF の場合: off_actions 配列
        ↓
アクションを配列インデックス順に逐次実行
  ※ 1つのアクションが失敗しても後続アクションは実行継続（フェイルオープン）
        ↓
実行結果を action_result メッセージで Rust Core へ通知
```

### 2.4 エラーハンドリング

- アクション実行失敗時: 後続アクションの実行を継続する
- エラー内容は `action_result` メッセージの `error` フィールドに格納し Rust → React へ中継
- React はトースト通知でエラーをユーザーに表示する
- 開発者モード OFF 時に `shell` / `applescript` を実行しようとした場合: Sidecar がエラーを返す（UI ガードに加えてサーバーサイドでも拒否）

## 3. UI 仕様

### 3.1 画面一覧

| 画面 | 起動方法 | 説明 |
|---|---|---|
| メニューバーアイコン | 常時表示 | アプリの状態（Online/Offline）をアイコンで示す |
| ダッシュボードウィンドウ | アイコンクリック | 設定・状態確認の主画面。タブ構成 |

### 3.2 ダッシュボード タブ構成

#### ホームタブ

| 要素 | 仕様 |
|---|---|
| Matter サーバーステータス | Online / Offline のバッジ表示 |
| QRコード画像 | ペアリング前のみ表示。コミッショニング完了後は「ペアリング済み」表示に切り替わる |
| Manual Pairing Code | QRコードが読み取れない場合用の11桁数字コード |
| Setup PIN | 8桁の数字 |
| アクセシビリティ権限 | ✅ 付与済み / ⚠️ 未付与（「設定を開く」ボタン付き） |
| オートメーション権限 | 同上 |

#### スイッチタブ

| 要素 | 仕様 |
|---|---|
| スイッチカード × 10 | スイッチ番号・名前（編集可）・割り当てマクロ名を表示 |
| 割り当て変更ボタン | 既存マクロ一覧から選択するドロップダウンまたはモーダル |
| 未割り当て表示 | `assigned_macro_id` が null の場合「未割り当て」と表示 |

#### マクロタブ

| 要素 | 仕様 |
|---|---|
| マクロ一覧 | 作成済みマクロの名前一覧 |
| 新規作成ボタン | マクロエディタを空状態で開く |
| 編集・削除ボタン | 各マクロ行に配置 |

#### マクロエディタ（モーダルまたはサブ画面）

| 要素 | 仕様 |
|---|---|
| マクロ名入力 | テキストフィールド |
| ON 時アクションリスト | アクションの追加・削除・順序変更（ドラッグ&ドロップ） |
| OFF 時アクションリスト | 同上 |
| アクション追加 | タイプ選択 → 各タイプのフィールドを入力。開発者モード OFF 時は `shell` / `applescript` のタイプ選択肢を非表示 |

#### 設定タブ

| 要素 | 仕様 |
|---|---|
| ログイン時に自動起動 | トグルスイッチ。`system.auto_start` に保存 |
| 開発者モード | トグルスイッチ。`system.developer_mode` に保存。ON にする際に確認ダイアログを表示する |

## 4. IPC 通信仕様

### 4.1 React ↔ Rust（Tauri IPC コマンド）

**React → Rust（invoke）:**

| コマンド名 | パラメータ | 戻り値 | 説明 |
|---|---|---|---|
| `get_config` | なし | `Config` | 設定 JSON の取得 |
| `save_config` | `config: Config` | `void` | 設定 JSON の上書き保存 |
| `get_pairing_info` | なし | `PairingInfo \| null` | QRコード文字列・Manual Code・PIN の取得 |
| `get_permissions` | なし | `PermissionStatus` | macOS 権限状態の取得 |
| `open_accessibility_settings` | なし | `void` | プライバシー設定（アクセシビリティ）を開く |

**Rust → React（Tauri イベント）:**

| イベント名 | ペイロード | 説明 |
|---|---|---|
| `device-status-changed` | `{ endpoint_id: number, state: boolean }` | スイッチの ON/OFF 状態変化 |
| `action-error` | `{ endpoint_id: number, error: string }` | アクション実行エラー |
| `sidecar-offline` | `{}` | Sidecar プロセスが予期せず終了 |

### 4.2 Rust ↔ Node.js Sidecar（stdin/stdout JSON メッセージング）

メッセージフォーマット: `{"type":"<種別>","payload":{...}}\n`（改行 `\n` をデリミタとして使用）

**Rust → Sidecar (stdin):**

| `type` | payload 定義 | 説明 |
|---|---|---|
| `config_update` | `{ endpoints: Endpoint[], macros: Macro[], developer_mode: boolean }` | 設定変更の即時反映 |
| `shutdown` | `{}` | 正常終了の指示 |

**Sidecar → Rust (stdout):**

| `type` | payload 定義 | 説明 |
|---|---|---|
| `ready` | `{}` | Matter サーバー起動完了 |
| `qr_code` | `{ qr_payload: string, manual_code: string, discriminator: number, pin: number }` | コミッショニング情報 |
| `device_status` | `{ endpoint_id: number, state: boolean }` | ハブからの ON/OFF 状態変化 |
| `action_result` | `{ endpoint_id: number, action_index: number, success: boolean, error?: string }` | アクション実行結果 |

## 5. 設定データ仕様

### 5.1 保存パス

`~/Library/Application Support/com.matter-mac-agent/config.json`

### 5.2 型定義（TypeScript 表記）

```typescript
type Config = {
  system: SystemConfig;
  endpoints: Endpoint[];   // 常に10件（id: 1〜10）
  macros: Macro[];
};

type SystemConfig = {
  developer_mode: boolean;   // デフォルト: false
  auto_start: boolean;       // デフォルト: true
};

type Endpoint = {
  id: number;                           // 1〜10（固定）
  name: string;                         // デフォルト: "仮想スイッチ N"
  matter_type: "OnOffPluginUnitDevice"; // 現在固定。将来の拡張用フィールド
  assigned_macro_id: string | null;     // null = 未割り当て
};

type Macro = {
  id: string;          // UUID v4
  name: string;
  on_actions: Action[];
  off_actions: Action[];
};

type Action =
  | { type: "shortcut";    name: string; input: string }
  | { type: "open";        target: string }
  | { type: "shell";       command: string }
  | { type: "applescript"; script: string };
```

## 6. セキュリティ仕様

| 項目 | 仕様 |
|---|---|
| UI-コア間通信 | Tauri IPC のみ。localhost ポート開放なし。LAN 内他端末からのアクセス経路が物理的に存在しない |
| 開発者モードガード（UI） | `developer_mode: false` 時、マクロエディタで `shell` / `applescript` タイプの選択肢を非表示にする |
| 開発者モードガード（Sidecar） | `developer_mode: false` の場合、`shell` / `applescript` アクションの実行を Sidecar 側でも拒否し `action_result.error` を返す |
| 設定ファイル | Tauri の `app_data_dir()` が返す OS 標準のアプリデータディレクトリに保存。他アプリからのアクセスを OS 権限で制限 |
| Matter 通信 | UDP/TCP はローカルネットワーク内のみ。外部ネットワークへの通信なし |
| 権限表示 | アクセシビリティ・オートメーション権限の不足を UI で明示し、ユーザーへの透明性を確保する |
