# Matter Mac Agent ユーザーマニュアル

---

## はじめに

Matter Mac Agent は、Mac をスマートホームから操作できる **Matter Bridge デバイス**に変えるメニューバー常駐アプリです。Google Home / Apple Home / Alexa から「電気をつけて」と言うだけで、Mac でショートカット・アプリ起動・シェルコマンドなどを実行できます。通信はすべて LAN 内で完結し、クラウドへのデータ送信はありません。

---

## 動作環境

| 項目 | 要件 |
|---|---|
| macOS | Ventura 13.0 以降 |
| スマートホームハブ | Google Nest Hub / Apple HomePod / Amazon Echo（Matter 対応機種） |
| ネットワーク | Mac とハブが同一 Wi-Fi に接続されていること |

---

## インストールと起動

1. `.dmg` ファイルをダブルクリックし、`Matter Mac Agent.app` を `/Applications` にドラッグします。
2. アプリを起動すると、メニューバー右上にアイコンが表示されます。
3. アイコンをクリックするとダッシュボードが開きます。

> **初回起動時の Gatekeeper 警告について**
> 「開発元が未確認」と表示された場合は、Finder でアプリを右クリック → 「開く」を選択してください。

## 初期セットアップ

### 1. アクセシビリティ権限を付与する

ショートカットや AppleScript を正しく実行するには、アクセシビリティ権限が必要です。

- ダッシュボードの **ホームタブ** を開くか、アプリ起動直後に表示されるバナーの **「設定を開く」** をクリックします。
- システム設定 → プライバシーとセキュリティ → アクセシビリティ が開きます。
- 一覧の **Matter Mac Agent** をオンにします。

### 2. スマートホームハブとペアリングする

1. ダッシュボードの **ホームタブ** を開きます。
2. Matter サーバーが **Online** になるまで数秒待ちます。
3. QR コードが表示されたら、スマートホームアプリでスキャンします。
   - **Google Home**: ホーム画面右上「+」→「デバイスのセットアップ」→「Matter デバイスをセットアップ」
   - **Apple Home**: ホーム画面右上「+」→「アクセサリを追加」→「その他のオプション」
   - **Alexa**: デバイスタブ「+」→「デバイスを追加」→「Matter」
4. ペアリングが完了すると、10 個の仮想スイッチが自動登録されます。
5. ホームタブが「**ペアリング済み**」に切り替わります。

> **QR コードの代わりにコードを手入力する場合**
> 「Manual Pairing Code」に表示されている数字列を使用できます。

## ダッシュボードの使い方

メニューバーアイコンをクリックするとダッシュボードが開きます。右クリックでは「ダッシュボードを開く」「終了」のメニューが表示されます。ウィンドウの × ボタンはアプリを終了せず、ダッシュボードを閉じるだけです。

### ホームタブ

| 項目 | 説明 |
|---|---|
| Matter サーバー | Online / Offline のステータス |
| ペアリング | QR コード・PIN・ペアリング済み表示 |
| macOS 権限 | アクセシビリティ権限の付与状態 |

### スイッチタブ

10 個の仮想スイッチを管理します。

- **名前の変更**: テキストフィールドをクリックして直接編集します。名前はスマートホームアプリ側には自動反映されません（再ペアリングが必要です）。
- **マクロ割り当て**: プルダウンから実行するマクロを選択します。未割り当ての場合、そのスイッチの ON/OFF は何も実行しません。

### マクロタブ

マクロを作成・編集・削除します。マクロは ON 時アクションと OFF 時アクションをそれぞれ複数登録できます。

#### 新規マクロの作成

1. **新規マクロ** ボタンをクリックします。
2. マクロ名を入力します（例：「開発環境起動」）。
3. **ON 時アクション** / **OFF 時アクション** にアクションを追加します。
4. **保存** をクリックします。

#### アクションの種類

| 種類 | 説明 | 例 |
|---|---|---|
| ショートカット | macOS ショートカットアプリのショートカットを実行 | ショートカット名: `開発環境を起動`、入力: `""` |
| アプリ / URL を開く | アプリや URL を `open` コマンドで開く | `/Applications/Xcode.app` / `https://example.com` |
| シェルコマンド | bash コマンドを実行（開発者モード限定） | `pbcopy <<< "パスワード"` |
| AppleScript | AppleScript を実行（開発者モード限定） | `tell application "Finder" to open home` |

> **アクションの実行順序**: 上から順番に実行されます。1 つのアクションが失敗しても、後続のアクションは継続して実行されます。

#### マクロの削除

削除時にそのマクロを割り当てていたスイッチは自動的に「未割り当て」に戻ります。

### 設定タブ

| 設定 | 説明 |
|---|---|
| ログイン時に自動起動 | Mac ログイン時に Matter Mac Agent を自動起動します |
| 開発者モード | シェルコマンドと AppleScript アクションを有効にします |

> **開発者モードについて**: 有効化すると、任意のシェルコマンドや AppleScript をスマートホームから実行できるようになります。信頼できる環境でのみ使用してください。有効化時に確認ダイアログが表示されます。

## スマートホームでの使い方

ペアリング後、Google Home / Apple Home / Alexa で通常のスマート家電と同様に操作できます。

### 音声操作の例

| 操作 | Google Home | Apple Home (Siri) |
|---|---|---|
| 仮想スイッチ 1 を ON にする | 「〇〇をオンにして」 | 「〇〇をオンにして」 |
| ルーティンに組み込む | Google Home アプリでルーティン設定 | ショートカットアプリでオートメーション設定 |

「〇〇」はスイッチタブで設定した名前（デフォルト: 「仮想スイッチ 1」〜「仮想スイッチ 10」）です。わかりやすい名前に変更することをお勧めします。

### 活用例

| やりたいこと | 設定内容 |
|---|---|
| 「仕事モード開始」で Xcode と Slack を起動 | ON アクション: 「アプリを開く」× 2（Xcode / Slack） |
| 「おやすみ」でスクリーンセーバー起動 | ON アクション: Shell `open -a ScreenSaverEngine` |
| Siri でパスワードをクリップボードにコピー | ON アクション: Shell `pbcopy <<< "pass"` |
| Google Home のルーティンでバックアップを実行 | ON アクション: ショートカット「バックアップ」 |

## トラブルシューティング

### Matter サーバーが Offline のまま

- アプリを再起動してください（メニューバーアイコン右クリック → 終了 → 再起動）。
- Mac がスリープから復帰した直後は数秒かかることがあります。
- Wi-Fi に接続されているか確認してください。

### QR コードが表示されない

- Matter サーバーが Online になるまで待ってください（最大 10 秒程度）。
- Online なのに QR コードが表示されない場合は、アプリを再起動してください。

### ペアリングできない

- Mac とスマートホームハブが同一 Wi-Fi（同一サブネット）にいることを確認してください。
- ファイアウォールが Matter の UDP ポートをブロックしていないか確認してください。
- 一度ペアリングした後にアンペアリングして再ペアリングする場合は、`~/Library/Application Support/com.matter-mac-agent/matter/` フォルダを削除してから再起動してください。

### アクションが実行されない

- スイッチタブでマクロが割り当てられているか確認してください。
- エラー内容はダッシュボード右下にトースト通知として表示されます。
- ショートカットアクションの場合、ショートカットアプリで該当ショートカットが正しく動作するか確認してください。
- Shell / AppleScript アクションが動作しない場合は、設定タブで開発者モードがオンになっているか確認してください。

### 「アクセシビリティ権限が必要です」バナーが表示される

- ホームタブの「設定を開く」ボタンをクリックし、システム設定でアクセシビリティ権限を付与してください。

---

## アンインストール

1. アプリを終了します（メニューバーアイコン右クリック → 終了）。
2. `/Applications/Matter Mac Agent.app` をゴミ箱に移動します。
3. 設定データを削除する場合は `~/Library/Application Support/com.matter-mac-agent/` フォルダも削除します。

スマートホームアプリ側からも登録済みのデバイスを削除してください。

---

## 設定ファイルの場所

`~/Library/Application Support/com.matter-mac-agent/config.json`

テキストエディタで直接編集できますが、アプリ起動中は変更が上書きされる場合があります。編集はアプリ終了後に行ってください。
