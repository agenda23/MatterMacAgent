# Matter Mac Agent ユーザーマニュアル

---

## はじめに

Matter Mac Agent は、Mac をスマートホームから操作できる **Matter Bridge デバイス**に変えるメニューバー常駐アプリです。Google Home / Apple Home / Alexa から「電気をつけて」と言うだけで、Mac 上でショートカット・アプリ起動・シェルコマンドなどを実行できます。通信はすべて LAN 内で完結し、クラウドへのデータ送信はありません。

本アプリの最もおすすめの使い方は、**macOS 標準の「ショートカット」アプリ**で自動化を組み立て、スマートホームのスイッチ操作から呼び出すことです。GUI で直感的に設定でき、安全で、再利用しやすいため、初めての方にも最適です。

## このアプリでできること

| できること | 説明 |
|---|---|
| スマートホームから Mac を操作 | 音声アシスタントやルーティンで仮想スイッチ ON/OFF |
| 10 個の独立スイッチ | 1 台の Mac から最大 10 種類の自動化を割り当て可能 |
| マクロで複数アクションを連続実行 | ON 時・OFF 時それぞれに複数ステップを登録 |
| 完全ローカル動作 | インターネット不要・クラウド不使用 |

**仮想スイッチ 1 つ** = スマートホーム上の「電気のスイッチ」1 個。ON にすると登録したマクロの「ON 時アクション」が、OFF にすると「OFF 時アクション」が実行されます。

## 動作環境

| 項目 | 要件 |
|---|---|
| macOS | Ventura 13.0 以降 |
| ショートカットアプリ | macOS 標準搭載（Monterey 以降。本アプリは Ventura 13.0 以降が必要） |
| スマートホームハブ | Google Nest Hub / Apple HomePod / Amazon Echo（Matter 対応機種） |
| ネットワーク | Mac とハブが同一 Wi-Fi に接続されていること |

## インストールと起動

1. `.dmg` ファイルをダブルクリックし、`Matter Mac Agent.app` を `/Applications` にドラッグします。
2. アプリを起動すると、メニューバー右上にアイコンが表示されます（Dock には表示されません）。
3. アイコンを **左クリック** するとダッシュボードが開きます。**右クリック** では「ダッシュボードを開く」「終了」メニューが表示されます。
4. ウィンドウの × ボタンはアプリを終了せず、ダッシュボードを閉じるだけです。バックグラウンドで Matter サーバーは動き続けます。

> **初回起動時の Gatekeeper 警告について**
> 「開発元が未確認」と表示された場合は、Finder でアプリを右クリック → 「開く」を選択してください。

## 初期セットアップ

### 1. アクセシビリティ権限を付与する

UI 操作を含む AppleScript（System Events による操作など）や、集中モード・スクリーンショットなど一部のショートカットアクションを実行するには、アクセシビリティ権限が必要です。付与しておくと、すべてのアクションが確実に動作します。

1. ダッシュボードの **ホームタブ** を開くか、アプリ起動直後に表示されるバナーの **「設定を開く」** をクリックします。
2. システム設定 → プライバシーとセキュリティ → **アクセシビリティ** が開きます。
3. 一覧の **Matter Mac Agent** をオンにします。

### 2. スマートホームハブとペアリングする

1. ダッシュボードの **ホームタブ** を開きます。
2. Matter サーバーが **Online** になるまで数秒待ちます。
3. QR コードが表示されたら、スマートホームアプリでスキャンします。
   - **Google Home**: ホーム画面右上「+」→「デバイスのセットアップ」→「Matter デバイスをセットアップ」
   - **Apple Home**: ホーム画面右上「+」→「アクセサリを追加」→「その他のオプション」
   - **Alexa**: デバイスタブ「+」→「デバイスを追加」→「Matter」
4. ペアリングが完了すると、10 個の仮想スイッチが自動登録されます。
5. ホームタブが「**ペアリング済み**」に切り替わります。

> **QR コードの代わりにコードを手入力する場合**
> 「Manual Pairing Code」に表示されている数字列を使用できます。

> **スイッチ名について**
> スイッチタブで変更した名前は、スマートホームアプリ側には自動反映されません。スマートホーム上の表示名を変えたい場合は、再ペアリングが必要です（後述のトラブルシューティング参照）。

## macOS ショートカットアプリ連携ガイド

このセクションでは、**ショートカットアプリで自動化を作り、Matter Mac Agent 経由でスマートホームから実行する**手順を詳しく説明します。本アプリの最も安全でおすすめの使い方です。

### なぜショートカットを使うのか

| 方法 | メリット | 向いている用途 |
|---|---|---|
| **ショートカット**（推奨） | GUI で組み立てられる・権限管理しやすい・再利用しやすい | 日常的な自動化全般 |
| アプリ / URL を開く | 設定が最もシンプル | 単一アプリの起動だけ |
| シェル / AppleScript | 柔軟性が高い | 上級者向け（開発者モードが必要） |

ショートカットアプリなら、「アプリを起動 → 待機 → テキストを入力 → 通知を表示」のような複数ステップを、コードを書かずに組み立てられます。

### ショートカットアプリを開く

1. Spotlight（`⌘ + Space`）で「**ショートカット**」と入力して Enter。
2. または、Launchpad → **ショートカット** をクリック。
3. 左サイドバーに「すべてのショートカット」「フォルダ」などが表示されます。

### ショートカットの作り方（基本）

#### ステップ 1: 新規ショートカットを作成

1. ショートカットアプリ右上の **「+」** をクリックします。
2. 空のショートカットが表示されます。上部の「新規ショートカット」を **わかりやすい名前** に変更します（例: `仕事モード開始`）。
   - **重要**: この名前を、後で Matter Mac Agent のマクロに **そのまま** 入力します。名前は完全一致が必要です。

#### ステップ 2: アクションを追加

1. 右側の検索欄で使いたいアクションを探します（例: 「アプリを開く」「通知を表示」「待機」「メモに追加」）。
2. アクションをダブルクリックまたはドラッグして、左のワークフローに追加します。
3. 各アクションのパラメータ（アプリ名、待機秒数など）を設定します。
4. 複数アクションは **上から順番** に実行されます。

#### ステップ 3: 動作確認

ショートカットを Matter Mac Agent に登録する前に、必ず単体でテストしてください。

**方法 A: ショートカットアプリから実行**

1. 作成したショートカットを選択します。
2. 右上の **▶（実行）** ボタンをクリックします。
3. 意図どおり動作するか確認します。

**方法 B: ターミナルから実行（本アプリと同じ方法）**

Matter Mac Agent は内部的に `/usr/bin/shortcuts run` コマンドでショートカットを呼び出します。ターミナルで同じコマンドを試すと、本番と同じ動作を確認できます。

```bash
# 基本形（入力なし）
shortcuts run "仕事モード開始"

# 入力テキストを渡す場合（標準入力に渡される）
echo "買い物リスト" | shortcuts run "メモを追記"
```

エラーが出る場合は、ショートカット名のスペルや権限を見直してください。

#### ステップ 4: Matter Mac Agent のマクロに登録

1. Matter Mac Agent のダッシュボード → **マクロタブ** を開きます。
2. **新規マクロ** をクリックし、マクロ名を入力します（例: `仕事モード`）。
   - マクロ名とショートカット名は **別物** です。マクロ名は Matter Mac Agent 内の管理用ラベルです。
3. **ON 時アクション** で種類を「**ショートカット**」にします。
4. フィールドを入力します。

| フィールド | 入力内容 | 例 |
|---|---|---|
| ショートカット名 | ショートカットアプリに表示されている名前（完全一致） | `仕事モード開始` |
| 入力（任意） | ショートカットに渡すテキスト。不要なら空欄 | `会議資料` または空欄 |

5. 必要なら **OFF 時アクション** にも別のショートカットを登録します（例: OFF 時に `仕事モード終了` を実行）。
6. **保存** をクリックします。

#### ステップ 5: スイッチにマクロを割り当て

1. **スイッチタブ** を開きます。
2. 使いたいスイッチ（例: 仮想スイッチ 1）の名前を変更します（例: `仕事モード`）。
3. マクロのプルダウンから、先ほど作成したマクロを選択します。
4. スマートホームアプリでそのスイッチを ON にすると、ショートカットが実行されます。

### 「入力（任意）」フィールドの使い方

「入力」に文字を書くと、ショートカット実行時に **標準入力（stdin）** として渡されます。ショートカット側では、**「ショートカットの入力」マジック変数** を使ってどのアクションからでも受け取れます。専用のアクションを先頭に追加する必要はありません。

| シーン | 入力欄 | ショートカット側での扱い |
|---|---|---|
| 入力不要 | 空欄のまま | 「ショートカットの入力」変数を参照しなければよい |
| 固定テキストを渡す | `牛乳とパン` など | 使いたいフィールドに「ショートカットの入力」変数を挿入 |

**「ショートカットの入力」変数の使い方**

1. 入力を使いたいアクションのテキストフィールドをクリックします。
2. 表示されるメニューから **「ショートカットの入力」** を選択します（青いカプセル状の変数として挿入されます）。
3. 保存すれば、Matter Mac Agent の「入力」欄に書いた文字列がそのまま渡されます。

> 入力が不要なショートカットでは、入力欄は **空欄** のままで問題ありません。

### おすすめの活用例

#### 例 1: 仕事モード — 複数アプリを一括起動

**ショートカット「仕事モード開始」の構成**

1. アプリを開く → Slack
2. アプリを開く → Xcode
3. 待機 → 2 秒
4. 通知を表示 → 「仕事モードを開始しました」

**Matter Mac Agent の設定**

| 項目 | 値 |
|---|---|
| マクロ名 | 仕事モード |
| ON 時アクション | ショートカット: `仕事モード開始`、入力: 空欄 |
| OFF 時アクション | ショートカット: `仕事モード終了`（任意で作成） |
| スイッチ名 | `仕事モード` |

**スマートホームでの操作**: 「仕事モードをオンにして」

---

#### 例 2: おやすみモード — 集中モードの切り替え

集中モード（Focus）の切り替えは、アクセシビリティ権限不要で確実に動作するためおすすめです。

**ショートカット「おやすみ ON」の構成**

1. 集中モードを設定 → 「おやすみ」を「オン」（終了時刻を指定することも可能）
2. ミュージックの再生を一時停止
3. 通知を表示 → 「おやすみなさい」

**ショートカット「おやすみ OFF」の構成**

1. 集中モードを設定 → 「おやすみ」を「オフ」

**Matter Mac Agent の設定**

| 項目 | 値 |
|---|---|
| ON 時アクション | ショートカット: `おやすみ ON` |
| OFF 時アクション | ショートカット: `おやすみ OFF` |
| スイッチ名 | `おやすみ` |

「おやすみ」以外の集中モード（「仕事」「パーソナル」など）にも同じ手順で使えます。

---

#### 例 3: メモ追記 — 固定テキストをメモに記録

スマートホームのルーティンを起点に、決まった文言をメモへ追記する例です。

**ショートカット「メモに追記」の構成**

1. 「メモに追加」アクション
   - メモ: 「買い物」（事前に作成しておく）
   - テキスト: **「ショートカットの入力」** 変数を選択（青いカプセル状の変数）

**Matter Mac Agent の設定**

| 項目 | 値 |
|---|---|
| ON 時アクション | ショートカット: `メモに追記`、入力: `牛乳とパン` |
| スイッチ名 | `買い物メモ` |

> スイッチごとに渡す文言を変えれば、「牛乳」「洗剤」など品目別のスイッチを作れます。

---

#### 例 4: バックアップの実行

**ショートカット「夜間バックアップ」の構成**

1. シェルスクリプトを実行（Time Machine や rsync など、あらかじめ用意したスクリプト）
2. 完了したら通知を表示

**Matter Mac Agent の設定**

| 項目 | 値 |
|---|---|
| ON 時アクション | ショートカット: `夜間バックアップ` |
| スイッチ名 | `バックアップ` |

ショートカット内で複雑な処理をまとめておけば、Matter Mac Agent 側はシンプルなまま運用できます。

---

#### 例 5: 朝・夜のディスプレイ設定切り替え

ON/OFF それぞれに別のショートカットを割り当てる例です。

| スマートホームの操作 | 実行されるアクション |
|---|---|
| スイッチ ON（夜） | ショートカット「夜モード」: Night Shift をオン → 輝度を下げる |
| スイッチ OFF（朝） | ショートカット「昼モード」: Night Shift をオフ → 輝度を戻す |

1 つのマクロに ON 用・OFF 用ショートカットをそれぞれ登録することで、スマートホームのトグル操作に連動した正反対の自動化が作れます。

> Apple Home のオートメーションと組み合わせれば「日没時に夜モード ON」「日の出時に昼モード ON」といった時間連動制御も実現できます。

### ショートカット作成のコツ

| コツ | 説明 |
|---|---|
| 名前は短く明確に | スマートホームの音声操作で呼びやすい名前にする（スイッチ名と揃えると覚えやすい） |
| 1 ショートカット = 1 目的 | 複雑になりすぎたら、ON 用・OFF 用で分割する |
| 必ず単体テストする | `shortcuts run "名前"` で確認してからマクロに登録 |
| 通知を入れる | 実行されたかどうかが視覚的にわかり、デバッグにも役立つ |
| 待機を入れる | アプリ起動直後に操作すると失敗することがある。1〜3 秒の「待機」を挟む |
| 名前に制約はない | Matter Mac Agent はショートカット名をシェルを介さず直接渡すため、日本語・スペース・記号を含む名前でも動作します |

### ショートカットが動かないとき

| 症状 | 確認すること |
|---|---|
| 「ショートカットが見つからない」 | ショートカット名が **完全一致** しているか（全角/半角・スペースに注意） |
| 何も起きない | ターミナルで `shortcuts run "名前"` を実行してエラーを確認 |
| 一部のアクションだけ失敗 | ショートカットアプリ単体で ▶ 実行し、どのアクションで止まるか確認 |
| 権限エラー | Matter Mac Agent のアクセシビリティ権限、ショートカットの「プライバシー」設定を確認 |
| ダッシュボードにエラー表示 | 右下のトースト通知にエラー内容が表示されます |

## 全体の流れ（クイックリファレンス）

初めて設定する場合の流れをまとめます。

```
① Matter Mac Agent をインストール・起動
        ↓
② アクセシビリティ権限を付与
        ↓
③ スマートホームハブとペアリング（QR コード）
        ↓
④ ショートカットアプリで自動化を作成・テスト
        ↓
⑤ Matter Mac Agent のマクロに「ショートカット」アクションを登録
        ↓
⑥ スイッチタブでマクロを割り当て
        ↓
⑦ スマートホームから ON/OFF → Mac でショートカット実行
```

## ダッシュボードの使い方

### ホームタブ

| 項目 | 説明 |
|---|---|
| Matter サーバー | Online / Offline のステータス |
| ペアリング | QR コード・PIN・ペアリング済み表示 |
| macOS 権限 | アクセシビリティ権限の付与状態 |

### スイッチタブ

10 個の仮想スイッチを管理します。

- **名前の変更**: テキストフィールドをクリックして直接編集します。スマートホームアプリ側の表示名は自動反映されません。
- **マクロ割り当て**: プルダウンから実行するマクロを選択します。未割り当ての場合、そのスイッチの ON/OFF は何も実行しません。

### マクロタブ

マクロを作成・編集・削除します。マクロは ON 時アクションと OFF 時アクションをそれぞれ複数登録できます。

#### 新規マクロの作成

1. **新規マクロ** ボタンをクリックします。
2. マクロ名を入力します（例: `開発環境起動`）。
3. **ON 時アクション** / **OFF 時アクション** にアクションを追加します。
4. **保存** をクリックします。

#### アクションの種類

| 種類 | 説明 | 例 |
|---|---|---|
| **ショートカット**（推奨） | macOS ショートカットアプリのショートカットを実行 | 名前: `仕事モード開始`、入力: 空欄 |
| アプリ / URL を開く | アプリ・URL・ファイルを開く。URL スキームも使用可能 | `/Applications/Xcode.app`、`https://example.com`、`obsidian://` |
| シェルコマンド | zsh コマンドを実行（**開発者モード限定**） | `pbcopy <<< "パスワード"` |
| AppleScript | AppleScript を実行（**開発者モード限定**） | `tell application "Finder" to open home` |

> **アクションの実行順序**: 上から順番に実行されます。1 つのアクションが失敗しても、後続のアクションは継続して実行されます。

#### マクロの削除

削除時にそのマクロを割り当てていたスイッチは自動的に「未割り当て」に戻ります。

### 設定タブ

| 設定 | 説明 |
|---|---|
| ログイン時に自動起動 | Mac ログイン時に Matter Mac Agent を自動起動します |
| 開発者モード | シェルコマンドと AppleScript アクションを有効にします |

> **開発者モードについて**: 有効化すると、任意のシェルコマンドや AppleScript をスマートホームから実行できるようになります。信頼できる環境でのみ使用してください。有効化時に確認ダイアログが表示されます。通常の利用では **ショートカットアプリ** で十分です。

## スマートホームでの使い方

ペアリング後、Google Home / Apple Home / Alexa で通常のスマート家電と同様に操作できます。

### 音声操作の例

| 操作 | 言い方の例 |
|---|---|
| 仮想スイッチを ON | 「〇〇をオンにして」 |
| 仮想スイッチを OFF | 「〇〇をオフにして」 |
| ルーティンに組み込む | 各アプリのルーティン / オートメーション設定でスイッチをトリガーに指定 |

「〇〇」はスイッチタブで設定した名前（デフォルト: 「仮想スイッチ 1」〜「仮想スイッチ 10」）です。**音声で呼びやすい名前**に変更することをお勧めします（例: `仕事モード`、`おやすみ`、`バックアップ`）。

### ルーティン連携のヒント

| プラットフォーム | 設定場所 |
|---|---|
| Google Home | Google Home アプリ → ルーティン → スターターにデバイスを追加 |
| Apple Home | ホームアプリ → オートメーション → アクセサリの状態が変化したとき |
| Alexa | Alexa アプリ → ルーティン → スマートホームデバイスをトリガーに追加 |

例: 「毎朝 7 時に `仕事モード` スイッチを ON」→ Mac で仕事用ショートカットが実行される、といった連携が可能です。

## トラブルシューティング

### Matter サーバーが Offline のまま

1. アプリを再起動してください（メニューバーアイコン右クリック → 終了 → 再起動）。
2. 起動後 **10 秒ほど** 待ってからホームタブを確認してください（初回はランタイム展開に時間がかかります）。
3. それでも Offline の場合は、Sidecar ランタイムのキャッシュを削除して再起動します。

```bash
rm -rf ~/Library/Application\ Support/com.matter-mac-agent/sidecar-runtime
```

4. `.app` を再インストールした直後は、上記キャッシュ削除後に再起動すると確実です。
5. Wi-Fi に接続されているか確認してください。

> **補足**: Offline は Sidecar（Matter エンジン）が起動できていない状態です。アプリをアップデートしたあと古いキャッシュが残っていると発生することがあります。

### QR コードが表示されない

- Matter サーバーが Online になるまで待ってください（最大 10 秒程度）。
- Online なのに QR コードが表示されない場合は、アプリを再起動してください。
- すでにペアリング済みの場合は QR コードの代わりに「ペアリング済み」と表示されます。

### ペアリングできない

- Mac とスマートホームハブが同一 Wi-Fi（同一サブネット）にいることを確認してください。
- ファイアウォールが Matter の UDP ポートをブロックしていないか確認してください。
- 再ペアリングする場合は、スマートホームアプリ側でデバイスを削除したうえで、`~/Library/Application Support/com.matter-mac-agent/matter/` フォルダを削除してからアプリを再起動してください。

### ショートカット / アクションが実行されない

1. **スイッチタブ** でマクロが割り当てられているか確認します。
2. **マクロタブ** でショートカット名が正しいか確認します（ショートカットアプリの名前と完全一致）。
3. ターミナルで `shortcuts run "ショートカット名"` を実行し、単体で動作するか確認します。
4. エラー内容はダッシュボード右下の **トースト通知** に表示されます。
5. Shell / AppleScript が動作しない場合は、設定タブで **開発者モード** がオンか確認してください。

### 「アクセシビリティ権限が必要です」バナーが表示される

- ホームタブの「設定を開く」ボタンをクリックし、システム設定で Matter Mac Agent のアクセシビリティ権限をオンにしてください。

### Mac がスリープ中に動かない

- Matter Mac Agent は Mac が起動・ネットワーク接続されている必要があります。スリープ中はコマンドを受信できません。常時稼働させたい場合は、システム設定 → ロック画面 / バッテリーでスリープ設定を調整してください。

## アンインストール

1. アプリを終了します（メニューバーアイコン右クリック → 終了）。
2. `/Applications/Matter Mac Agent.app` をゴミ箱に移動します。
3. 設定データを削除する場合は `~/Library/Application Support/com.matter-mac-agent/` フォルダも削除します。

スマートホームアプリ側からも登録済みのデバイスを削除してください。作成したショートカットはショートカットアプリに残るため、必要に応じて個別に削除してください。

---

## 設定ファイルの場所

`~/Library/Application Support/com.matter-mac-agent/config.json`

テキストエディタで直接編集できますが、アプリ起動中は変更が上書きされる場合があります。編集はアプリ終了後に行ってください。
